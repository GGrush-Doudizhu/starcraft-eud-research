# StarCraft EUD Research

This repository publishes bilingual research on StarCraft EUD programming, with a focus on the runtime control-flow mechanics, usage patterns, and optimization techniques of eudplib.

The current study analyzes `EUDIf`, `EUDIfNot`, `EUDElseIf`, `EUDElse`, `EUDBranch`, conditional loop exits, and low-level `nextptr` optimization. Its implementation analysis is based on eudplib 0.80.6.

## Research Scope

The documents cover:

- the trigger structure generated by `EUDBranch`;
- the actual relationship between `EUDIf` and `EUDIfNot`;
- branch-condition selection based on runtime frequency;
- direct `RawTrigger` optimization;
- safe merging and relocation of reset Actions;
- early loop exits with `EUDContinueIf` and `EUDContinueIfNot`;
- filtering live Protoss Zealots with both high-level and manually optimized forms;
- `if-else` and `else-if` control-flow structures; and
- common optimization mistakes and a practical optimization workflow.
